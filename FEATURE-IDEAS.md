# FEATURE-IDEAS — One Score

Parking lot. Nothing here gets built mid-phase. Pull an idea into VAULT-PLAN.md only between phases, on purpose.

## After launch (n8n layer)
- Parent monthly report (email with a Share Lock link)
- Sport coach weekly summary; alert after `override.sport_red_streak` Red days
- Owner monthly report: check-in compliance, zone mix, overrides, availability (feeds ABIR)
- Red same-day alert to the coach

## Product
- Anchor top-set log so training maxes update between test days
- Bar speed check (`test.bar_speed`)
- Body-map soreness location (`body.location`)
- Sport-specific phase dates (per sport instead of per facility)
- Multi-facility Owner view (one Owner, several tenants)
- Upper-body anchor swap library for No lower body days
- Printable / PDF export of a facility's Setup answers
- Philosophy notes (the old Layer 1 "why" questions) as optional text in Setup
- Coach-board reminders: max re-test due (`test.max_retest_weeks`), bodyweight update due (`profile.bw_update`)
- Use `test.yellow` / `test.red` once testing beyond the weekly check-in box exists

## Open questions
- **Athlete login for minors.** The Standard requires real email + 8-character passwords. Some schools won't give students emails an app can use. Options: parent email invites (current plan), school email, or a documented exception. Decide before selling to a school.
- Does a facility pay per athlete, flat, or inside the Facility System Install retainer?
